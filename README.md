# PocketLedger

> 一个主打轻量、本地优先、可快速记账的微信小程序项目。

PocketLedger 是一个面向日常生活场景的个人记账小程序。它在保留快速录入体验的同时，把预算、订阅管理、扣费提醒、多币种换算这些常见记账工具里容易缺失的能力也一起做了进来，适合用作课程项目、作品集项目，或者继续扩展成完整产品。

## 项目简介

这个项目主要解决三类问题：

- 日常收支怎么记得更快
- 月度预算怎么更直观地看
- 各类订阅服务怎么更清楚地管理

项目采用微信小程序原生能力开发，数据通过本地存储持久化，不依赖后端即可运行和演示，结构清晰，也比较适合前端练手和后续二次开发。

## 功能亮点

- 自定义数字键盘，提升记账录入效率
- 收入 / 支出双类型记账
- 常用分类快捷记账
- 月度预算设置与预算使用进度展示
- 订阅项目管理与到期提醒
- 订阅扣费日历视图
- 多币种订阅金额录入与人民币换算
- 年付订阅按月分摊能力
- 月度统计、分类占比、近 6 个月趋势分析
- 本地 JSON 数据导入 / 导出
- 本地优先，无需后端即可完整运行

## 主要功能模块

### 首页总览

首页是整个应用的核心面板，集中展示当前月的关键数据：

- 本月收入、支出、结余
- 月预算与预算使用比例
- 最近记账记录
- 即将到期的订阅项目
- 当前订阅月均成本概览
- 常用支出分类快捷入口
- 订阅扣费日历

它更像一个“财务驾驶舱”，适合每天打开快速查看和补记。

### 记账录入

支持收入和支出两类记录的新增、编辑与删除：

- 选择收入 / 支出类型
- 按类型切换分类
- 使用自定义数字键盘录入金额
- 快捷追加金额
- 选择日期
- 补充备注

整体交互偏向移动端高频场景，尽量减少输入成本。

### 账单列表

账单页用于按月复盘：

- 按月份筛选
- 按收入 / 支出筛选
- 按分类筛选
- 按日期分组展示记录
- 展示当月收入与支出汇总

### 统计分析

统计页聚焦“看懂花在哪”：

- 月度收入、支出、结余统计
- 当月记录数
- 支出 / 收入占比
- 支出分类占比
- 近 6 个月收支趋势

### 订阅管理

项目把订阅管理作为独立能力来处理，而不是只把它当备注信息：

- 新增 / 编辑订阅项目
- 支持周付、月付、季付、年付
- 设置提醒天数
- 启用 / 暂停订阅
- 一键续费并推进下次扣费日期
- 查看即将到期订阅
- 统计订阅月均成本与年成本

### 多币种订阅支持

对于海外软件或平台类订阅，项目提供了多币种支持：

- 订阅可选择币种
- 录入时展示人民币换算预览
- 汇率通过远程接口获取
- 本地缓存 24 小时
- 网络失败时使用内置兜底汇率

这部分能力让订阅成本更容易横向比较，也更适合做月度预算规划。

### 设置与数据管理

设置页目前包含：

- 月预算配置
- 显示货币切换
- 本地记录数 / 订阅数查看
- 全量数据导出为 JSON
- 从剪贴板导入 JSON 数据
- 清空本地数据

## 本地运行方式

### 环境要求

- 微信开发者工具
- Node.js（可选，主要用于依赖安装和编辑器提示）

### 启动步骤

1. 克隆仓库到本地
2. 使用微信开发者工具打开项目目录
3. 确认项目配置文件为 `project.config.json`
4. 确认小程序根目录为 `miniprogram/`
5. 在开发者工具中运行预览

### 安装依赖

```bash
npm install
```

当前项目依赖非常轻量，主要使用：

- `miniprogram-api-typings`

## 本地存储说明

PocketLedger 目前通过微信小程序本地存储保存所有核心数据，主要键名包括：

- `pocket_records`
- `pocket_subscriptions`
- `pocket_settings`
- `pocket_exchange_rates`

这意味着：

- 不需要后端即可完整运行
- 本地读写速度快
- 项目更适合演示和前端开发练习
- 如果需要长期备份，建议定期导出数据

## 汇率处理策略

项目当前通过以下接口获取汇率数据：

- `https://open.er-api.com/v6/latest/CNY`

处理逻辑如下：

- 优先使用本地缓存汇率
- 缓存有效期为 24 小时
- 可用时异步刷新最新汇率
- 网络失败时回退到内置兜底汇率

这样的设计可以在保证体验的同时，避免页面强依赖网络请求。
